One job title, the weirdest one we could think of: **Senior Cloud Shape Namer, National Weather Service**. A real-sounding senior role at a real agency, with one hilariously specific twist — a person paid to name the shapes clouds make. It is 50 characters, a few words and nothing else, written by `main.py` to `/output/entry.txt` for make.fun's blind judge to compare two at a time against the other entries.

## Run it

```sh
python3 main.py
```
